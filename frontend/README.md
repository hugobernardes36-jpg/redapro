# RedaPro Frontend

Frontend MVP em React + JavaScript + Vite + CSS, sem integração com backend.

## Rodar

```bash
npm install
npm run dev
```

## Fluxo

/login → /inicio → /nova-redacao → /resultado
                 ↘ /minhas-redacoes → /redacao
                 ↘ /temas
                 ↘ /perfil

Os dados estão em `src/data/mocks.js` para facilitar a futura troca por API.
